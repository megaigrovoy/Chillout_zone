# Chillout Zone

Интерактивное развлечение на React: MediaPipe отслеживает ладони через
веб-камеру, и из руки раскрываются самоподобные спиральные узоры — каждый
завиток повторяет себя в меньшем масштабе, снова и снова.

Всё обрабатывается локально в браузере — видеопоток никуда не отправляется.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173 и разрешите доступ к камере.

Веб-камера требует защищённого контекста (secure context): `localhost` подходит,
а при открытии по IP в локальной сети нужен HTTPS.

## Управление

Трекинг идёт **только по ладони** — положение, поворот и раскрытость. Отдельные
пальцы не отслеживаются: их дрожание раньше расшатывало фигуру, а жест «поднять
руку» проще и надёжнее.

| Жест | Что происходит |
| --- | --- |
| Раскрыть ладонь | Узор ветвится шире, фигуры рождаются чаще |
| Сжать кулак | Тугая плотная спираль, эмиссия реже |
| Повернуть кисть | Наклон всей фигуры |
| Поднять руку выше | Больше уровней вложенности |
| Приблизить к камере | Фигура крупнее |

Левая рука голубая, правая — пурпурная.

## Как это работает

**Это IFS, а не органический рост.** Предыдущая версия выращивала ленты со
случайной кривизной, шумом и вихревым полем — получался красивый куст, но не
фрактал: каждая ветвь была уникальна. Настоящее самоподобие означает, что мелкий
завиток на кромке крупного — это *та же самая кривая* в меньшем масштабе, а не
похожая на неё.

Поэтому фигура строится системой итерируемых функций: фиксированный набор
преобразований «повернуть + сжать + сдвинуть», применяемый рекурсивно. Все
случайные величины выбираются **один раз на фигуру** (`IfsSpec`) и дальше не
меняются — именно это сохраняет самоподобие внутри узора, но оставляет разными
соседние узоры.

**Спираль — логарифмическая, то есть равноугольная.** Угол между радиусом и
касательной постоянен на всей кривой. Это и есть формальный критерий
самоподобия: любой кусок такой спирали, увеличенный, совпадает с целым. Замер
показывает угол 77.593° с отклонением 0.000000° по всей длине.

**Узор раскрывается во времени, а не рисуется разом.** У каждого луча есть
`progress`, дети рождаются, когда родитель раскрыт на 55% — поэтому фигура
именно *растёт*, а детали доплетаются позади фронта.

**«Бесконечность» — это пиксели, а не объекты.** Нарисованное копится на
отдельном offscreen-слое и очень медленно затухает, а в памяти живут только
раскрывающиеся фигуры. Час рисования стоит столько же памяти, сколько секунда.

**Полосы слоистые.** Внутри каждой ленты — пять параллельных рёбер от почти
чёрного ядра к светлому гребню, плюс тёмный шов по оси. Число рёбер фиксировано,
поэтому мелкая копия луча имеет ту же внутреннюю структуру, что и крупная, —
самоподобие читается на любом масштабе. Полосы непрозрачны и перекрывают друг
друга: аддитивный режим вымыл бы пересечения в белый.

## Структура

```
src/
  tracking/
    types.ts             типы состояния руки
    handState.ts         сведение landmark'ов MediaPipe в сигнал ладони
    useHandTracking.ts   камера + цикл распознавания
  fractal/
    ifs.ts               логарифмическая спираль и точки крепления детей
    bloom.ts             рекурсивное раскрытие фигуры во времени
    band.ts              отрисовка слоистой полосы
    params.ts            маппинг рук в параметры + сглаживание
    render.ts            двухслойный рендер: накопление + эмиссия фигур
  components/
    FractalCanvas.tsx    цикл рендера на requestAnimationFrame
  App.tsx                экран запуска, HUD, отладочные данные
```

Решения, которые стоит знать при доработке:

- **Трекинг передаётся через ref, а не через state.** При 30–60 кадрах в секунду
  `setState` на каждый кадр перерисовывал бы всё дерево React и ронял бы FPS.
- **Параметры сглаживаются экспоненциально** с шагом от реального `dt`. Ощущение
  одинаковое на 30 и 144 Гц, а кратковременная потеря руки не даёт рывка.
- **`dt` ограничен сверху.** Вкладка, вернувшаяся из фона, иначе сделала бы один
  гигантский шаг.
- **Глубоким лучам достаётся меньше точек выборки** (`46 / (1 + depth)`): луч
  четвёртого уровня шириной в несколько пикселей не нуждается в такой же
  детализации, как ствол.
- **Ресайз сохраняет рисунок** — накопительный слой переносится на новый холст.
- **Handedness инвертируется** относительно MediaPipe: модель сообщает сторону с
  точки зрения камеры, а картинка зеркалится под зрителя.

Модель и WASM-рантайм MediaPipe загружаются с CDN при первом запуске — для старта
нужен интернет. Чтобы работало офлайн, положите `hand_landmarker.task` и wasm-файлы
в `public/` и поправьте `WASM_ROOT` и `MODEL_URL` в `useHandTracking.ts`.

## Настройка ощущения

- `render.ts` — `specFor()` задаёт характер узора: `turns` (сколько оборотов),
  `b` (насколько раскрыта спираль), `ratio` (во сколько раз мельче каждый
  уровень), `branchAngle` (угол отхода детей), `depth` (уровней вложенности).
  Там же `MAX_BLOOMS`/`MAX_ARMS`, скорость раскрытия и `decay` (как долго живёт
  нарисованное)
- `band.ts` — `RIBS` (слоистость полосы), формула `light` (контраст ядра и гребня)
- `ifs.ts` — `attachPoints()` (где на родителе сидят дети), профиль ширины луча
- `handState.ts` — `OPENNESS_MIN`/`OPENNESS_MAX` (калибровка раскрытости ладони)

# Chillout Zone

Интерактивное развлечение на React: MediaPipe отслеживает руки игрока через веб-камеру,
а фракталы на экране меняют конфигурацию в зависимости от движения кистей.

Всё обрабатывается локально в браузере — видеопоток никуда не отправляется.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173 и разрешите доступ к камере.

Веб-камера требует защищённого контекста (secure context): `localhost` подходит,
а при открытии по IP в локальной сети нужен HTTPS.

## Управление

| Жест | Что меняется |
| --- | --- |
| Раскрыть / сжать левую ладонь | Разброс ветвей и их количество (2–5) |
| Поворот левой кисти | Закрутка формы — из симметричного дерева в спираль |
| Поднять / опустить правую руку | Глубина рекурсии (4–10 уровней) |
| Раскрыть правую ладонь | Длина дочерних ветвей |
| Приблизить руку к камере | Общий масштаб фрактала |
| Двигать руку по горизонтали | Палитра (оттенок) |
| Двигаться быстрее | Энергия: свечение и толщина линий |

Видны обе руки — левая управляет формой, правая ростом. Если видна одна рука,
она управляет всеми параметрами сразу.

## Как устроено

```
src/
  tracking/
    types.ts             типы состояния руки
    handState.ts         сведение 21 точки MediaPipe в пригодный сигнал
    useHandTracking.ts   камера + цикл распознавания
  fractal/
    params.ts            маппинг рук в параметры фрактала + сглаживание
    render.ts            рекурсивная отрисовка на canvas
  components/
    FractalCanvas.tsx    цикл рендера на requestAnimationFrame
  App.tsx                экран запуска, HUD, отладочные данные
```

Несколько решений, которые стоит знать при доработке:

- **Трекинг передаётся через ref, а не через state.** При 30–60 кадрах в секунду
  `setState` на каждый кадр перерисовывал бы всё дерево React и ронял бы FPS.
  Цикл рендера читает `frameRef.current` напрямую.
- **Параметры сглаживаются экспоненциально** (`easeParams`) с шагом, зависящим от
  реального `dt`. Поэтому ощущение одинаковое и на 30, и на 144 Гц, а кратковременная
  потеря руки не даёт рывка.
- **Число сегментов ограничено** (`MAX_SEGMENTS` в `render.ts`). Глубина и ветвление
  перемножаются: 10 уровней по 5 ветвей — это миллионы отрезков и зависший таб.
- **Кадр не очищается, а затемняется** полупрозрачным прямоугольником — отсюда шлейфы.
  Отрисовка идёт в режиме `lighter`, поэтому пересечения ветвей светятся ярче.
- **Handedness инвертируется** относительно того, что отдаёт MediaPipe: модель
  сообщает сторону с точки зрения камеры, а картинка зеркалится под зрителя.

Модель и WASM-рантайм MediaPipe загружаются с CDN при первом запуске — для старта
нужен интернет. Чтобы работало офлайн, положите `hand_landmarker.task` и wasm-файлы
в `public/` и поправьте `WASM_ROOT` и `MODEL_URL` в `useHandTracking.ts`.

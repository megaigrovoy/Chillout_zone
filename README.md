# Chillout Zone

Интерактивное развлечение на React: MediaPipe отслеживает руки через веб-камеру,
из кисти во все стороны разрастаются спиральные фрактальные ленты, текут по
вихревому полю рук, сплетаются между собой и медленно тают.

Всё обрабатывается локально в браузере — видеопоток никуда не отправляется.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173 и разрешите доступ к камере.

Веб-камера требует защищённого контекста (secure context): `localhost` подходит,
а при открытии по IP в локальной сети нужен HTTPS.

## Управление

| Жест | Что происходит |
| --- | --- |
| Раскрыть ладонь | Из кисти веером расходится больше лент, вихрь становится широким |
| Сжать кулак | Поток отталкивается от руки, эмиссия почти останавливается |
| Повернуть кисть | Меняется направление и сила закрутки вихря |
| Поднять руку выше | Ростки живут дольше и уходят дальше |
| Двигать рукой быстро | Вихрь мешает сильнее, растёт свечение |
| Свести две руки | Ветви встречаются, вспыхивают и связываются перемычками |

Левая рука голубая, правая — пурпурная. Цвет перемычек — среднее между ними.

## Как это работает

Три идеи, на которых держится вся вещь.

**Фрактал — это популяция, а не рекурсия.** Первая версия перерисовывала дерево
рекурсией каждый кадр, поэтому фрактал не мог ни расти, ни жить. Сейчас это
популяция растущих кончиков (`Tip`), которая переживает кадры: каждый кончик
продвигается на шаг, рисует свой сегмент и иногда делится. Рука его только сеет
и направляет.

**Ветви — ленты, а не линии.** Нитевидные штрихи читаются как проволочная схема.
Объём даёт `ribbon.ts`: каждый шаг рисуется как сужающаяся полоса, залитая
несколькими вложенными слоями (тёмное ядро → светлый гребень), с бликом по
внешней кромке и гроздьями мелких самоподобных завитков с тёмным «глазом» в
центре. Ленты кладутся непрозрачно и перекрывают друг друга — именно
перекрытие даёт слоистую глубину раковин; аддитивный режим вымыл бы всё в белый.

**Ленты летят по логарифмическим спиралям.** У каждой линии есть постоянная
скорость поворота (`curl`), а не прямое направление. Соседние лучи закручиваются
в разные стороны, а дети закручиваются туже родителя (`curl * 1.25…1.55`) —
отсюда вложенность спиралей внутри спиралей. Из кисти лучи расходятся веером на
полный круг, поэтому форма растёт во все стороны, а не только куда указывают
пальцы.

**«Бесконечность» — это пиксели, а не объекты.** Нарисованное копится на
отдельном offscreen-слое и очень медленно затухает. Поэтому час рисования стоит
ровно столько же памяти, сколько секунда, — структура живёт как краска на холсте,
а в памяти держится только фронт роста. Замеры на симуляции: 120 секунд игры
двумя руками дают те же 0.71 мс на кадр, что и 30 секунд (0.74 мс).

**Популяция ограничивает себя сама.** У каждого кончика есть запас энергии;
ветвление делит его между потомками, кончик с нулевой энергией умирает. Поэтому
численность стабилизируется (в среднем ~410 лент при двух руках, пик ~990 при
потолке 1100) — ветви заканчиваются естественно, а не обрубаются.

### Вихревое поле

Каждая рука создаёт вихрь: поворот кисти задаёт направление вращения, раскрытость —
радиус, скорость движения — силу. Кончики не летят по прямой, а плавно
подворачивают по полю, поэтому две руки перемешивают потоки как жидкость.

Падение силы вихря ограничено у ядра (`Math.max(dist, r * 0.12)`) — без этого
член 1/r взрывается и кончики рядом с ладонью улетают с абсурдной скоростью.

### Взаимодействие

`entangle.ts` ищет пары кончиков от *разных* рук ближе 46 px и рисует между ними
перемычку: чем ближе встреча, тем ярче. Это единственное по-настоящему
квадратичное место в кадре, поэтому ограничено и число проверяемых кончиков
(каждый третий), и число перемычек за кадр.

## Структура

```
src/
  tracking/
    types.ts             типы состояния руки
    handState.ts         сведение 21 точки MediaPipe в пригодный сигнал
    useHandTracking.ts   камера + цикл распознавания
  fractal/
    field.ts             вихревое поле рук
    growth.ts            популяция растущих спиральных лент
    ribbon.ts            отрисовка ленты: слои, блик, кружево завитков
    entangle.ts          перемычки между формами разных рук
    params.ts            маппинг рук в параметры + сглаживание
    render.ts            двухслойный рендер: накопление + живой фронт
  components/
    FractalCanvas.tsx    цикл рендера на requestAnimationFrame
  App.tsx                экран запуска, HUD, отладочные данные
```

Ещё пара решений, которые стоит знать при доработке:

- **Трекинг передаётся через ref, а не через state.** При 30–60 кадрах в секунду
  `setState` на каждый кадр перерисовывал бы всё дерево React и ронял бы FPS.
- **Параметры сглаживаются экспоненциально** с шагом от реального `dt`. Ощущение
  одинаковое на 30 и 144 Гц, а кратковременная потеря руки не даёт рывка.
- **`dt` ограничен сверху.** Вкладка, вернувшаяся из фона, иначе сделала бы один
  гигантский шаг и вышвырнула все кончики за экран.
- **Ресайз сохраняет рисунок** — накопительный слой переносится на новый холст,
  иначе изменение размера окна стирало бы всё накопленное.
- **Handedness инвертируется** относительно MediaPipe: модель сообщает сторону с
  точки зрения камеры, а картинка зеркалится под зрителя.

Модель и WASM-рантайм MediaPipe загружаются с CDN при первом запуске — для старта
нужен интернет. Чтобы работало офлайн, положите `hand_landmarker.task` и wasm-файлы
в `public/` и поправьте `WASM_ROOT` и `MODEL_URL` в `useHandTracking.ts`.

## Настройка ощущения

Самое интересное живёт в константах:

- `growth.ts` — `SPEED` (скорость роста), `MAX_TIPS` (потолок популяции),
  `branchEvery` (густота ветвления), `seedCooldown` (частота эмиссии из руки),
  `curl` при рождении и множитель `curl` у детей (насколько туго всё закручено)
- `ribbon.ts` — `LAYERS` (слоистость заливки), `baseR`/`count` в `drawLace`
  (размер и густота кружева по кромке)
- `render.ts` — коэффициент в `decay` (как долго живёт нарисованное)
- `entangle.ts` — `LINK_DIST` (на каком расстоянии формы начинают связываться)
- `field.ts` — `strength`/`radius`/`radial` в `fieldFromHands` (характер вихрей),
  `hue` левой и правой руки
- `handState.ts` — `OPENNESS_MIN`/`OPENNESS_MAX` (калибровка раскрытости ладони)
